# Kit Cursor — site DATA TRACE SERVICE

1. Décompresser à la racine du projet (dossier dts-site) et ouvrir dans Cursor.
2. Vérifier Réglages > Rules : dts-core, dts-design, dts-api chargées.
3. Ouvrir prototype/dts.html dans un navigateur pour voir les maquettes (?s=adash, ?s=apages… pour l'espace Gérante).
4. Lancer les prompts dans l'ordre : prompts/00 à prompts/15, une étape à la fois, avec validation et commit entre chaque.
5. Tests : npm i -D @playwright/test && npx playwright install chromium.
